Magenta Cutout Tool - bundled dependency notices

This standalone Windows x64 application bundles a Python runtime and libraries.
Their original license and notice files are included in this directory.

Tested build:
  CPython 3.10.6
  Tcl/Tk 8.6.12
  Pillow 11.3.0
  NumPy 2.2.6
  opencv-python 5.0.0.93
  psutil 7.2.2
  charset-normalizer 3.4.3
  PyInstaller 6.22.2 (build tool and bootloader)

These libraries remain under their respective licenses. PyInstaller's included
license explains the bootloader exception. Third-party notices shipped with
OpenCV, NumPy and Pillow are retained in the copied files.
