# 마영란 — 철마산역 히로인 이벤트 전체 대본

기준 시점: 중원력 732년 3월 상순 게임 시작  
대상 지역: 철마산역 전역  
목적: 마영란 히로인 루트의 지역별 발생 조건, 맵 선택지, 선택 결과, 이벤트 내부 전체 대화를 한 문서에서 확인하기 위한 테스트용 설계안

> 이 문서는 이벤트 설계·대본 문서다. 실제 챕터 MD, staging.json, presentation.json에 그대로 넣는 파일은 아니다. 실제 구현 단계에서는 각 이벤트를 고유 대사 ID로 분리하고, 한 ID가 한 화면이 되도록 최신 대본·연출 매뉴얼 기준으로 다시 편집한다.
>
> 강산은 1인칭 중심이며 평소에는 가볍고 실전적인 농담을 조금 섞는다. 위험한 순간에는 농담 빈도를 낮춘다. 마영란은 척후답게 관찰력이 좋고 말수가 아주 많은 편은 아니지만, 친해질수록 건조한 농담과 짧은 받아치기가 늘어난다.
>
> 연애는 호감도만으로 열리지 않는다. 신뢰, 비밀 유지, 강산의 행동 성향이 핵심이다.

## 0. 루트 변수

| 변수 | 의미 |
|---|---|
| `my_met` | 마영란과 첫 만남을 끝냈는가 |
| `my_route_stage` | 루트 진행 단계 0~6 |
| `my_trust` | 신뢰도 |
| `my_affection` | 호감도 |
| `my_suspicion` | 강산의 산 감각에 대한 의심 |
| `my_debt` | 서로 목숨을 빚진 정도 |
| `my_secret_known` | 마영란이 강산의 산 관련 능력을 일부 아는가 |
| `my_kept_secret` | 마영란이 보고 과정에서 강산의 비밀을 숨겼는가 |
| `my_companion` | 현재 동행 중인가 |
| `my_romance` | 연애 루트 확정 |
| `my_route_failed` | 개인 루트 실패 |

기본 진행은 `미조우 → 경계 → 반복 조우 → 임시 협력 → 신뢰 → 비밀 의심 → 비밀을 지켜줌 → 상호 의존 → 연애 가능` 순서다.

# 18. 구현 시 선택지 원칙

1. **진행 선택지**  
   이벤트를 실제로 연다. 예: 도와준다 / 조사한다 / 같이 간다.

2. **보류 선택지**  
   한 번 거절했다고 히로인 루트가 즉시 끝나지 않는다. 기간 이벤트가 아니라면 다음 방문에 다시 발생 가능하다.

3. **성향 선택지**  
   같은 이벤트를 진행해도 강산의 행동에 따라 마영란의 신뢰·호감이 달라진다.

4. **실패 선택지**  
   민간인 학살·고문·고의적 배신처럼 강산의 핵심 성향을 크게 벗어난 행동이 누적될 때만 루트 실패에 가까워진다.

5. **호감과 신뢰 분리**  
   농담·선물·데이트는 호감을 올릴 수 있지만 핵심 비밀과 생사 문제는 신뢰가 부족하면 진행되지 않는다.

6. **지역과 히로인 기능 연결**  
   마영란 이벤트를 보면 대사만 늘어나는 것이 아니라 안개재 샛길, 매복 감지, 달개울채 내부정보, 윤가 병력 정찰 같은 실제 플레이 이득이 생긴다.
