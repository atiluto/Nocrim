# 녹림전생 — 게임 대본 편집실

여기는 **게임에서 읽는 대사와 연출을 편집하는 원본**이다. 세계관·인물 설정은 `universe/`, 웹소설 문장 원고는 `universe/09_웹소설형_시나리오.md`에서 관리한다. 대본과 소설은 서로 덮어쓰지 않는다.

다른 Chat에 수정을 맡길 때는 [대본·연출 편집 매뉴얼](시나리오_대본과_연출_편집매뉴얼.md)을 함께 전달한다. 캐릭터 이동·화면 밖 등장과 퇴장·겹침·놀람·회상·암전·음향의 문법과 예제가 있다. 이동까지 수정하려면 챕터 MD뿐 아니라 `staging.json`, 날짜·위치 변경에는 `presentation.json`도 함께 전달한다.

## 대사를 고치는 방법

1. `chapters/00_프롤로그/common/`에서 수정할 장면 파일을 연다.
2. `대사:` 아래 문장을 수정한다. `화자:`도 필요하면 바꿀 수 있다. `P01-001` 같은 번호는 저장 위치를 찾는 값이므로 유지한다. 한 ID가 한 화면이며 MD의 줄바꿈을 그대로 유지한다. 대사 본문은 좌우 15% 여백을 두고 이어지며, 화면 폭을 넘을 때만 자동으로 줄이 바뀐다. 별도 화면이 필요하면 새 ID로 나눈다.
3. 프로젝트 루트의 `대사_적용.bat`을 실행한다. 대본 형식과 이미지·음원 경로를 검사한 뒤 게임용 데이터를 갱신한다.
4. 완료 메시지가 나오면 `play.bat`으로 확인한다. 오류가 나오면 창에 표시된 대사 번호와 항목을 수정한다.

대사뿐 아니라 화자·배경·인물·음악·연출을 바꿨거나 새로운 분기 구조가 필요한 경우에는 “scenario에서 수정한 대본을 게임에 반영해줘”라고 요청한다. BAT는 현재 구현된 형식을 변환하는 도구이며, 새로운 인물 등록이나 분기 기능을 스스로 만들어 주지는 않는다.

일반 Chat에서는 수정할 대사 번호와 새 문장을 보내면 된다. 기술 항목을 전부 편집할 필요는 없다. 같은 장면을 `universe/09`와 여기에서 서로 다르게 수정했다면 최신 요청을 기준으로 차이를 확인한다.

현재 날짜·위치·시간대는 `presentation.json`의 `scene_status`에서 대사 번호별로 편집한다. `calendar`의 `era`는 현대 `modern` / 무림 `murim`, `cycle`은 각 시작 상순부터 지난 순 수(0부터)다. 시작은 현대 2026년 6월 상순 / 무림 서력 732년 3월 상순이며, `date`는 적용할 때 자동 계산한다. `location`은 위치, `period`는 `아침`·`낮`·`밤` 중 하나다. 다음 지정 지점까지 유지하며 왼쪽 상단 챕터 제목 아래에 표시한다. `대사_적용.bat`으로 반영한다. 기존 프롤로그 경과 일수 배치는 같은 순서의 순으로 옮겼고, 한 달 경과는 3순이다. 프롤로그의 마지막 순 다음 아침부터 전략 모드가 이어진다.

## 챕터·루트·분기 구성

프롤로그는 11장면으로 구성된 하나의 공통 루트다. 원문에 없는 선택 결과를 만들지 않았다. 목차 이동과 장 넘김은 읽기 편의 기능이며 스토리 분기가 아니다.

분량이 늘면 `chapters/01_장제목/common/`, `chapters/01_장제목/routes/정파/`, `chapters/01_장제목/routes/녹림/`처럼 나눈다. 여러 장을 관통하는 루트 조건은 `routes/`에서 관리한다. 조건·선택지·합류점이 생기면 장면 ID로 연결하고 게임 처리도 함께 구현한다. 현재 재생기는 선형 프롤로그용이며 분기용 폴더를 만드는 것만으로 분기 엔진이 구현되지는 않는다.

## 연출 항목 읽는 법

| 항목 | 의미 |
|---|---|
| 화자 | 독백 또는 인물 이름. `독백`은 게임에서 이름표를 표시하지 않는다 |
| 배경 | black, room, rain, village, hut, stockade, road, camp. 장과 장소에 맞는 현대·무림 CG로 자동 연결 |
| 인물 / 위치 | 기존 단일 인물 표기 참고값. 현재 화면의 인물·배치는 아래 `staging.json`을 기준으로 함 |
| 음악 / 환경음 | audio 폴더 기준 파일 경로. 빈칸은 정지. 같은 경로는 계속 재생 |
| 효과음 | 해당 대사에 한 번 재생. 불러오기 시 중복 재생 억제 |
| 연출 | jump=놀람, shake=충격, walk=걷기, flash=전이, blackout=암전, fade/fadein=밝아짐 |
| 회상 | on부터 흐린 가장자리·낮은 채도 막·회상 표식을 적용하고 off에서 현재로 복귀. 빈칸은 앞 상태 유지 |
| 장면 | 대사에 이 항목이 있거나 `presentation.json`에 새 상태가 지정되면 암전으로 전환. 문구는 중앙에 표시하지 않음 |

캐릭터는 등장/퇴장에 이동과 투명도 전환을 사용한다. 같은 이미지는 대사마다 다시 등장하지 않는다. 장 전환은 약 1초, 날짜·시간·장소·배경 전환은 약 0.65초 동안 완전히 암전한다. 검은 화면에서 다음 배경과 상단 상태를 갱신하고 0.8초 머문 뒤 약 0.7~0.9초 동안 복귀한다. 중앙 제목·장소 카드와 전환 알림음은 표시·재생하지 않는다. 전환 중에는 대사 진행 입력을 받지 않으며, 목차 이동·장 넘김에도 동일하게 적용한다.

인물 연출은 `staging.json`에서 대사 번호별로 편집한다. `cast`는 인물 ID와 사용할 이미지·화자 이름·역할, `slots`는 좌우 자리와 등장 방향, `cues`는 배치와 일회성 동작이다. 같은 인물은 다른 사람이 말하거나 독백하는 동안에도 남아 있고, 말하는 사람은 밝게, 듣는 사람은 조금 어둡게 표시한다. 주인공은 계속 1인칭이므로 별도 얼굴을 추가하지 않는다.

- `stage`: 해당 시점부터 화면에 남을 인물 전체 목록. 뒤에 그릴 인물부터 앞에 그릴 인물 순으로 적는다. 생략하면 앞 배치를 유지하고, 빈 목록 `[]`이면 모두 퇴장한다. 챕터 시작은 빈 배치다. 최대 3명까지 동시 표시한다.
- `actor`: `cast`에 등록된 인물 ID. 이미지의 역할은 `sprite_roles`로 고정하며, `exclusive_sprites`의 전용 이미지는 지정된 한 인물만 사용한다. 산적을 상인·표국 무인·포로로 재활용하지 않는다. 한 화면에 같은 이미지 두 장을 배치할 수 없다.
- `slot`: `left`, `right`, `center`, `center_left`, `center_right`, `left_back`, `right_back`. 크기와 세로 위치는 고정하며 자리 이동은 약 0.46초 동안 좌우로만 한다. 겹침은 가로 위치와 인물 순서로 조정한다.
- `motions`: 대상 `actor`와 `motion` 지정. `approach`는 자리 이동 후 짧은 도약, `jump`는 놀람, `shake`는 짧은 좌우 떨림. 평상시 끄덕임은 제거했다. 접근할 때는 같은 cue의 `stage`에서 해당 인물을 중앙 자리로 옮긴다.
- `retired_at`: 사망 등으로 퇴장한 인물의 재등장 금지 시작 대사. 해당 시점 이후 같은 전용 이미지가 다시 나오면 변환 오류를 표시한다.

예를 들어 `P06-006`은 도망자를 왼쪽에 유지하면서 추격자를 중앙으로 이동시키고 `approach`를 실행한다. `P02-023-04`는 최억칠을 중앙에 배치해 어깨를 잡아당기는 장면을 표현한다. 수정 후 `대사_적용.bat`을 실행한다. 잘못된 인물·역할·자리·대사 번호는 변환 단계에서 알려준다. 불러오기에서는 일회성 동작을 반복하지 않으며, 저장 위치에서 전체 배치를 복원한다. 예전 자동 분할 페이지의 저장은 원본 ID의 대사로 복원한다.

현재 이미지 역할은 다음과 같다. `extra`는 더 이상 공용 이미지가 아니다.

| 이미지 이름 | 전용 역할 |
|---|---|
| npc_bandit_scout / npc_bandit_brute / extra | 박달수 / 조만식 / 최억칠. 2장 사망 후 재사용 금지 |
| npc_escort_guard / npc_escort_captain | 표국 무인 / 표국 장수 진여명. 사망 뒤 재사용 금지 |
| npc_bandit_raider | 5장 침입 산적 장혁. 사망 후 재사용 금지 |
| npc_bandit_patrol | 매골채 일반 산적. 민간인이나 표국으로 역할 변경 금지 |
| npc_merchant / npc_villager | 마을 상인 / 나무꾼 |
| npc_captive | 민간 포로·도망자 |
| mawung | 마웅철 |

자동 진행은 문장을 다 읽은 뒤 최소 2.2초 기다린다. 대사 기록·읽은 장 목차·장 넘김 확인창을 제공하며, 메뉴를 열거나 게임 창이 비활성화되면 자동 진행을 멈춘다. 회상 장면은 첫 대사에 `회상: on`, 현실로 돌아오는 첫 대사에 `회상: off`를 적는다.

시나리오 화면은 배경·캐릭터를 포함한 화면 전체 클릭으로 진행한다. 출력 중 클릭하면 현재 문장이 완성되고, 다시 클릭하면 다음 대사로 넘어간다. 저장·메뉴·기록·목차 등 버튼은 대사를 넘기지 않고 해당 기능만 실행한다.

## 구현 범위와 유의사항

- 09 원문을 11장 공통 프롤로그로 각색. 현재는 자동 페이지 분할 없이 원본 ID마다 한 화면을 표시하며 대본의 문장·줄바꿈·순서를 유지한다. 한 화면 1~2줄 정도의 호흡으로 작성한다.
- 9장의 전투 삽입 지시와 미확정 메모만 비탈·산기를 이용한 승리 및 포로 탈출 서술로 대체했다. 마웅철 생사/포로 여부는 확정하지 않았다. 실제 전투 시스템에 연결하지 않았다.
- 10장 귀산 시도 방향은 원문 그대로 보존했다. 능력의 실제 지도 시스템 전면 개편은 이번 범위가 아니다.
- 프롤로그 마지막 암전 후 기존 전략 모드의 거점으로 바로 이어진다. 담연화의 과거 도입 이벤트(opening)는 신규 시작·이어하기에서 건너뛴다. 기존 전략 자원·지역·동료 규칙을 사용하며 본편 전체를 새 소설 설정으로 재작성한 것은 아니다.
- 구버전 프롤로그 진행 중 저장은 새 프롤로그 첫 대사부터 시작한다. 본편·전투 저장 구조는 유지. 새 대본은 안정된 대사 ID로 이어 읽기 위치를 찾는다.
- 기존 투명 배경 파일은 유지한다. 역할을 분리하며 새로 만든 이미지 5장은 기존 제작 지시대로 흰 배경 원본이며, 수동 배경 제거 전에는 흰색이 보인다. 원본 비율을 유지하면서 하단을 화면 밖까지 내려, 몸통의 잘린 끝이 화면 안에 떠 보이지 않도록 배치한다.
- 음원은 제공 목록에서 선정했다. 경보 종은 전자 사이렌 대신 기존 metal_01 금속 타격음을 한 번 사용한 대체음이다. 음량은 시작값이며 청취·실행 믹싱 검증은 생략했다.

`대사_적용.bat`은 `tools/compile_scenario.py`로 Markdown을 검증하고 대사와 줄바꿈을 유지한 채 `godot/data/prologue.json`을 갱신한 뒤 일치 여부를 다시 확인한다. 이후 대사 수정 시 `prepare_prologue.py`로 재생성하지 않는다. 이 스크립트는 최초 각색 기록이며 기존 편집본 덮어쓰기를 거부한다.
