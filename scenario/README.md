# 녹림전생 — 게임 대본 편집실

여기는 **게임에서 읽는 대사와 연출을 편집하는 원본**이다. 세계관·인물 설정은 `universe/`, 웹소설 문장 원고는 `universe/09_웹소설형_시나리오.md`에서 관리한다. 대본과 소설은 서로 덮어쓰지 않는다.

## 대사를 고치는 방법

1. `chapters/00_프롤로그/common/`에서 수정할 장면 파일을 연다.
2. `대사:` 아래 문장을 수정한다. 한 화면은 1~2줄, 한 줄은 최대 28자로 유지한다(최대 글꼴 크기에서도 여유를 두는 기준). `화자:`도 필요하면 바꿀 수 있다. `P01-001` 같은 번호는 저장 위치를 찾는 값이므로 유지한다. 분할된 후속 대사는 `P01-001-02`처럼 번호가 붙는다.
3. “scenario에서 수정한 프롤로그 대본을 게임에 반영해줘”라고 요청한다. 수정한 파일이나 대사 번호만 알려줘도 된다.
4. 적용 담당이 변경점·화자·앞뒤 연출·음원 경로를 확인하고 게임용 데이터를 갱신한다. 문서 저장만으로 실행 중인 게임이 바뀌지는 않는다.

일반 Chat에서는 수정할 대사 번호와 새 문장을 보내면 된다. 기술 항목을 전부 편집할 필요는 없다. 같은 장면을 `universe/09`와 여기에서 서로 다르게 수정했다면 최신 요청을 기준으로 차이를 확인한다.

## 챕터·루트·분기 구성

프롤로그는 11장면으로 구성된 하나의 공통 루트다. 원문에 없는 선택 결과를 만들지 않았다. 목차 이동과 장 넘김은 읽기 편의 기능이며 스토리 분기가 아니다.

분량이 늘면 `chapters/01_장제목/common/`, `chapters/01_장제목/routes/정파/`, `chapters/01_장제목/routes/녹림/`처럼 나눈다. 여러 장을 관통하는 루트 조건은 `routes/`에서 관리한다. 조건·선택지·합류점이 생기면 장면 ID로 연결하고 게임 처리도 함께 구현한다. 현재 재생기는 선형 프롤로그용이며 분기용 폴더를 만드는 것만으로 분기 엔진이 구현되지는 않는다.

## 연출 항목 읽는 법

| 항목 | 의미 |
|---|---|
| 화자 | 독백 또는 인물 이름. 강산은 1인칭이며 별도 얼굴 미노출 |
| 배경 | room, rain, village, hut, stockade 또는 기존 road/camp |
| 인물 | extra=공용 단역, mawung=마웅철, 빈칸=퇴장 |
| 위치 | left 또는 right. 등장·퇴장은 같은 화면 가장자리 사용 |
| 음악 / 환경음 | audio 폴더 기준 파일 경로. 빈칸은 정지. 같은 경로는 계속 재생 |
| 효과음 | 해당 대사에 한 번 재생. 불러오기 시 중복 재생 억제 |
| 연출 | jump=놀람, shake=충격, walk=걷기, flash=전이, blackout=암전, fade=밝아짐 |

캐릭터는 등장/퇴장에 이동과 투명도 전환을 사용한다. 같은 이미지는 대사마다 다시 등장하지 않는다. 배경은 교차 전환하고, 자동 진행·대사 회상·읽은 장 목차·장 넘김 확인창을 제공한다. 메뉴를 열거나 게임 창이 비활성화되면 자동 진행을 멈춘다.

## 구현 범위와 유의사항

- 09 원문을 11장, 475개 대사 단위로 각색. 한 화면에 1~2줄씩 표시하도록 나누었으며 원문 문장과 순서를 유지했다. 효과음·놀람 등 일회성 연출은 분할 첫 화면에서만 실행한다.
- 9장의 전투 삽입 지시와 미확정 메모만 비탈·산기를 이용한 승리 및 포로 탈출 서술로 대체했다. 마웅철 생사/포로 여부는 확정하지 않았다. 실제 전투 시스템에 연결하지 않았다.
- 10장 귀산 시도 방향은 원문 그대로 보존했다. 능력의 실제 지도 시스템 전면 개편은 이번 범위가 아니다.
- 완료 화면에서 서장 재독 또는 타이틀 복귀. 타이틀의 기존 빠른 시작은 구버전 게임이며 새로운 프롤로그와 연속된 본편이 아니다.
- 구버전 프롤로그 진행 중 저장은 새 프롤로그 첫 대사부터 시작한다. 본편·전투 저장 구조는 유지. 새 대본은 안정된 대사 ID로 이어 읽기 위치를 찾는다.
- 캐릭터 흰색 배경 원본을 그대로 사용했다. 배경 제거는 아직 하지 않았으며 게임에도 흰 바탕이 보인다.
- 음원은 제공 목록에서 선정했다. 경보 종은 전자 사이렌 대신 기존 metal_01 금속 타격음을 한 번 사용한 대체음이다. 음량은 시작값이며 청취·실행 믹싱 검증은 생략했다.

적용 담당: `tools/compile_scenario.py`로 Markdown을 검증·변환해 `godot/data/prologue.json`을 갱신한다. `--check`는 문서와 게임 데이터가 같은지 확인한다. 이후 대사 수정 시 `prepare_prologue.py`로 재생성하지 않는다. 이 스크립트는 최초 각색 기록이며 기존 편집본 덮어쓰기를 거부한다.
