# 히로인 전용 루트 — 플레이와 MD 편집

2026-09-14. 마영란의 기존 대본/조건은 유지하며 **장소연·하령화**의 전용 루트를 추가했다. 신규 사건/상시 기능 20개, 기존 사건 확장 3개, 대사 MD 42개·228화면이다. 세 사람은 기존 지역 사건 관리자와 VN을 공유한다.

## 어디서 시작하는가

프롤로그 이후 샌드박스에서 **중원력 732년 4월 1일(상순)** 이후 방문한다. 기존 진행 중인 긴급/우선 사건이 있으면 그것이 먼저 나온다. 하루는 아침·낮·밤, 10일은 한 순이다. 대부분의 후속 사건은 앞 사건 완료부터 **실제 3일(9개 시간대)** 이후에 열린다. 즉시 이어 붙이지 않고 지도 표식을 따라 재방문한다.

| 인물 | 첫 장소 | 진행 |
|---|---|---|
| 장소연 | 솔바람 장시 | 숙박료→운임 장부→솔바람채 빈 방→거래소·운송업 투자→운송 손실→과거 계약 이야기→관계 선택→장날 후일담 |
| 하령화 | 청학산 | 상처 치료→솔바람채 포로→청학산 채집·동행→희귀 약재→적송산 치료→솔바람채 휴식→청학산 관계 선택→약방 후일담 |

‘나중에’/보류는 완료하지 않고 장소 메뉴로 돌아간다. 투자비가 모자라면 미뤘다가 자금을 마련할 수 있다. 장소연의 핵심 손실 사건은 돈 대신 직접 일하는 선택도 있다. 관계를 끊으면 해당 인물의 동행·후속 루트가 닫힌다. 후일담 뒤에도 샌드박스는 계속된다.

## 연애·동료·시간 제한

| 인물 | 연애 선택 조건 | 동료 선택 |
|---|---|---|
| 장소연 | 신뢰 55 이상, 호감 25 이상, 정직한 장부 확인, 운송 손실 책임 이행, 민간 피해 수치 1 이하 | 관계 확정 사건에서 연애 조건 없이 가능 |
| 하령화 | 신뢰 50 이상, 호감 25 이상, 치료 원칙 존중, 핵심 치료 또는 사후 수습 완료, 민간 피해 수치 1 이하 | 관계 확정 사건에서 연애 조건 없이 가능 |

하령화 **HR-JS-01**은 동행 단계와 희귀 약재 조건을 충족하면 방문하지 않아도 3일 기한이 시작된다. 지도 긴급 표식을 확인한다. 만료되면 환자가 다른 곳에서 치료받았다는 결과와 신뢰 감소가 한 번 기록된다. 솔바람채 **HR-SB-02**에서 약/식량을 보태거나 직접 일해 후속 수습을 할 수 있다. 보류해도 시계는 멈추지 않는다. 만료/수습 모두 저장된다.

## 동행과 장소 기능

각 인물의 세 번째 만남 이후 동행이 열린다. 장소 메뉴에서 각각 동행/따로 걷기를 바꾼다. 마영란의 기존 동행 상태와 독립적으로 저장한다.

- 장소연: 장시·나루 방문 시 시세/운임 정보 +1. 같은 장소에서는 하루 한 번. 물리적 흔적을 읽는 마영란 능력과 구분한다.
- 하령화: 철마산·청학산 방문 시 약초 +1. 같은 장소에서는 하루 한 번.
- SJ-C04 거래소: 투자금 60, 순마다 수입 +8. 장시에서 자금 12로 약초 2 구매.
- DN-C02 운송업: 투자금 80, 순마다 수입 +12. 나루에서 자금 10·행동 1로 식량 12 주문, 3일 쿨다운.
- HR-CARE: 동행 중 솔바람채에서 약초 1·행동 1로 건강 +18.

정기 수입은 기존 거점 수입과 함께 **순 변경 시** 정산한다. 동행을 잠시 끄는 것만으로 계약은 사라지지 않지만 장소연과 결별하면 두 계약 수입은 중지된다. 상시 구매/치료는 호감도를 올리지 않는다. 거래소의 별도 건물 화면·새 전투 능력은 추가하지 않았다.

## 다른 Chat에서 수정하기

1. [장소연 전용 루트](장소연_전용루트.md) 또는 [하령화 전용 루트](하령화_전용루트.md)를 전달한다. 설정·사건 순서·조건·선택·비용·결과가 모두 해당 MD에 있다.
2. 그 문서의 링크를 따라 수정할 `chapters/<사건 ID>/*.md`를 함께 전달한다. 대사는 `대사:` 아래, 한 ID는 한 화면이며 입력한 줄바꿈을 보존한다. 기존 ID를 재번호화하지 않는다.
3. 연출 수정에는 `scenario/events/staging.json`, `presentation.json`의 해당 ID와 [편집 매뉴얼](../../시나리오_대본과_연출_편집매뉴얼.md)을 함께 전달한다. [연출 기록](히로인_전용루트_연출기록.md)은 표정·배경·음향 검토용 사본이다.
4. 받은 수정본을 같은 위치에 저장하고 루트의 `대사_적용.bat`을 실행한다. 성공한 뒤 `play.bat`으로 실행한다.

루트 MD 안에 **정확히 하나의 `route-json` 코드 블록**을 유지한다. 일반 설명문은 게임 명령으로 읽지 않는다. JSON 쉼표·따옴표를 지키고, `nodes`의 대사 ID 목록과 다음 노드를 함께 확인한다. `END`는 완료, `DEFER`는 미완료 보류다. 대사 MD에 새 화면을 추가할 때는 이 목록에도 ID를 넣는다. 새 파일은 events/manifest.json의 chapters에 등록한다. 새 루트 패키지는 같은 manifest의 route_sources에 등록한다.

이번 루트의 SJ-C04·DN-C02·CH-C02는 `replace_events`에 명시되어 **catalog.json보다 우선**한다. 이 세 사건을 고칠 때는 루트 MD를 수정한다. 나머지 원래 사건은 catalog.json이 실행 원본이다. 출력인 godot/data JSON을 직접 고치면 다음 컴파일에서 덮인다. 초기 등록용 import/configure/extend 도구는 재실행하지 않는다.

## 저장값과 호환성

기존 regional 저장 구조를 사용하며 구세이브에 없는 값만 기본값으로 채운다. 리셋은 필요 없다. 마영란 완료 ID와 기존 프롤로그 ID는 유지했다. 예전부터 진행 중인 이벤트는 완료한 뒤 새 루트로 이동한다.

`regional.vars`의 `sy_`/`hr_` 공통 접미사: `met` 첫 만남, `stage` 진행 단계, `trust` 신뢰, `affection` 호감, `companion` 동행, `failed` 결별, `core` 핵심 사건, `romance` 연애, `ending` 관계 결과.

- 장소연 추가: `sy_honest`, `sy_tradepost`, `sy_transport`.
- 하령화 추가: `hr_rules`, `hr_missed`, `hr_recovered`.
- `regional.items.rare_herb`: 희귀 약재 수량.
- 기존 `regional.completed/pending/expired/cooldowns/counts/choices`에 새 사건도 같은 방식으로 기록한다. 완료 시간과 방문 보너스 날짜가 저장되므로 로드로 재보상하지 않는다.
- 장소별 하루 방문 보너스는 `regional.locations.<장소>.<인물ID>_visit_day`에 기록한다.

개발용 조건/수치 확인은 기존 event_debug 도구를 재사용한다. 예: variable의 key를 `sy_trust`/`hr_affection`으로 지정. 강제 실행은 조건을 대신 만들어 주지 않으므로 이후 분기 조건은 실제 수치를 확인한다.

## 미술과 구현 범위

기존 흰 배경 스프라이트 12종을 사용하고 새 대사마다 표정을 지정했다. 흰 배경은 사용자가 직접 제거한다. 새 바위틈·약방·나루 배경은 [Higgsfield 생성 기록](../../../art-source/heroines-routes-20260914/제작기록.md)에 원본/프롬프트를 보관했다. 마영란 바위틈 장면에도 새 배경을 연결했다. 장소연·하령화가 포함된 별도 한 장짜리 사건 CG는 추가 제작하지 않았다.

새 과거사와 행동 성향은 universe/07의 해당 인물 블록, 루트 개요는 universe/08에 기록했다. 전체 지역의 남은 사건·분기까지 완료한 것은 아니며 [사건 목록](../../../docs/EVENT_CATALOG.md)에 미구현을 보존했다.
