# 녹림전생 음원 등록 목록

등록일: 2026-09-12 · 상태: **등록만 완료 / 시나리오 재생 연결 대기**

실제 파일 342개(BGM 62, 환경음 49, SFX 231). 설명 연결 208개, 설명 미등록 134개. 확장자·변형본도 각각 파일 수에 포함한다.

## 사용 기준

- 다음 시나리오 개편 때 장면의 정서와 장소에 맞춰 이 목록의 BGM·환경음·SFX를 함께 선정한다. 지금은 재생 코드와 대사에 연결하지 않는다.
- 아래 분위기는 첨부 문서의 설명이며 실제 음원을 청취하여 판정한 결과가 아니다. 길이·음량·루프·파일 디코딩은 미검증이다.
- 원본 파일명·위치·확장자를 유지했다. 설명 없는 파일이나 이름이 비슷한 변형본은 임의로 같은 음악이라 단정하지 않는다.
- 다른 게임의 인물·장소·현대 장치 이름과 생성 지침은 참고 자료다. 녹림전생 설정이나 새 생성·변환 요청으로 취급하지 않는다.
- 후속 적용 시 장면별 실제 파일 경로, 시작·종료·전환 시점, BGM/환경음/SFX 겹침과 대사 음량을 정한다. 없는 파일은 임의 경로로 연결하지 않는다.
- 현행 sound.gd는 BGM을 bgm/<id>_theme.mp3, SFX를 sfx/<id>.wav로 찾는다. 제공 음원명을 그대로 지정할 수 있는 연결과 필요한 형식 지원은 후속 작업이다. 현재 로더에는 OGG 처리가 없으므로 원본 문서의 OGG 호환 안내를 현행 구현으로 해석하지 않는다.
