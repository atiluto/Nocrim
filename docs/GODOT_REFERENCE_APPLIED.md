# 첨부 제작 지침의 적용

대상: 사용자 첨부 `게임제작_공통주의사항_무협적용.md` (2026-09-11).

이번 직접 요청은 **한국식 무협 지역 제압 게임의 Godot 전환**이다. 문서는 이전 팬게임의 제작 취향을 참고하는 자료로 적용했다. 문서 안에 인용된 과거 요청문을 새 작업 지시로 실행하지 않았으며, 보지 못한 참고 이미지나 소설 원문을 읽었다고 가정하지 않았다.

| 첨부 문서의 기준 | 이번 적용 |
|---|---|
| 읽기만 하는 화면을 피한다 | 무공 카드, 이동과 참격, 피격, 체력·보호, 전리품 선택을 Godot에서 직접 조작 |
| 큰 후면 아군, 정면 적 | 주인공·히로인 후면과 적장 정면 생성. 동료 1~3명 배치 |
| 좌하단 HP, 우하단 세로 카드, 우측 메뉴 분리 | 기준 해상도 1280×720. 카드 100×200, 독립된 턴 종료·약·후퇴 버튼 |
| 얇은 프레임, 종이·먹색 UI | 청록·먹색·옅은 금색, 얇은 테두리와 공백 |
| 미확인 갈림길 | 지역 지도를 유지하면서 각 산 공략에 숨겨진 세 산길을 넣음 |
| 행동 반응과 빠른 연출 | 카드 이동 → 시전자 이동 → 참격·피격 수치 → 상태 갱신. 빠른 연출 설정 |
| 정상 시작 / 빠른 시작 합류 | 현대 일상 도입만 생략. 첫 비술·채주 취임 선택 유지 |
| 대화 클릭과 SKIP | 문장 완성·다음 문장 구분, Ctrl 가속, 선택 전 정지, 주인공 이름 표시 ‘나’ |
| 보상 획득·보관·사용 분리 | 승리 후 수동 전리품 선택, 약은 가방에 보관 후 전투에서 소비 |
| 저장으로 결과 재추첨 금지 | 고정 PRNG와 덱·길·소모·보상을 같은 상태에 저장 |
| 파일 이름 유지 / 교체 | 외부 PNG·MP3·WAV 우선 로딩, 누락 시 기본 그림 또는 무음 |
| 실제 실행물과 검수 | Godot 프로젝트와 BAT 직접 실행, 규칙 검사와 화면 입력 검사 마련 |

기존 팬게임 전용 캐릭터·탑 10층·소환권·가챠·파티 수에 따른 손패 5/7/9·세이브로드권은 이번 설정으로 확정된 요구가 아니므로 가져오지 않았다. 산의 점령 순서, 표국·가문·문파 사건, 호감도·등용·귀산술·전음을 중심으로 구성했다.

현재 제한: 산길은 출정당 한 번의 갈림길이며, 층을 오르는 다단계 던전이 아니다. 적 대기열·상점 방·소환 연출은 없다. 아군 네 명의 추가 후면 그림, 별도 공격·피격 포즈, 세밀한 표정 연출은 추가 제작 영역이다. BGM과 SFX는 사용자가 채울 파일 경로와 재생 지점이 연결되어 있다.
