# 0.1.0 검증 기록

2026-09-10 / Windows 10 x64 / Ren’Py 8.5.3.

## 확인한 것

- 공식 배포 SDK 다운로드 후 공식 SHA-256과 대조.
- Ren’Py 프로젝트 컴파일 및 Lint 실행.
- 순수 게임 규칙 검사 13개 통과: 상태 불변성·저장된 난수 재현·강적 기습 성공과 실패·점령 순서 대체 사건·표국에 따른 윤가 첫 만남·비술 목적지·약속을 요구하는 관계 사건·등용/석방 배타성·자원 부족 차단·편성/부상·산 재점령 중복 사건 방지·여섯 결말 조건.
- 위 검사에는 실제 모병·훈련·정산·출전 명령만 사용하여 처음부터 여덟 산을 통일하는 자동 플레이가 포함됩니다.
- 20개 시드에 대해 최대 200개 행동을 탐색하며 자원 음수·중복 인물·점령지 밖 주둔 등의 상태 오류를 검사했습니다.
- Ren’Py 실행 검사 `smoke`: 처음 화면 → 서장 → 선택 → 지도 → 모병 → 인물 → 정찰 → 편성 → 전투 → 퇴각 → 하루 마감 → 저장 → 불러오기 → 추가 훈련. 통과.
- Ren’Py 실행 검사 `narrative`: 대체 만남 → 가문 사건 → 관계 성립 → 강호록·도움말·설정 → 최종 선택 → 통일 결말 및 관계 후일담 → 처음 화면. 통과. 뒷부분 장면의 화면 검사는 테스트 전용 조건을 주입해 수행했으며, 해당 검사 자체가 전 캠페인을 수동으로 완주했다는 뜻은 아닙니다.
- 제목·지도·인물·선택지·전투·저장·결말의 실제 Ren’Py 렌더를 확인했습니다. 한글 및 기호의 글꼴 누락, 지도 연결선, 텍스트 영역 문제를 수정했습니다.

## 한계

모든 가능한 점령 순서와 모든 선택 조합을 사람이 완주한 것은 아닙니다. 밸런스와 장편 대사의 재미는 실제 플레이 피드백을 통해 다듬을 부분입니다. Windows x64 실행본을 대상으로 했으며 macOS·Linux 배포본은 이번에 만들지 않았습니다.

이 버전은 공통 배경 1장, 네 인물의 초상 아틀라스 1장, 무음 연출을 사용합니다. 성우, 표정 세트, 부대별 전투 애니메이션, 이벤트 전용 CG, 다중 연애 갈등은 구현하지 않았습니다.

테스트 저장파일·저장 서명 토큰·SDK·진단 스크린샷은 배포본 및 소스 묶음에서 제외합니다.
