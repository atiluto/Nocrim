# Godot판 검증 기록

버전: 0.2.0. 엔진: Godot 4.7.2 stable 표준판. Windows x64, OpenGL 호환 렌더러, NVIDIA RTX 4060 Laptop GPU에서 실행했다.

## 2026-09-12 지도 변경의 확인 범위

프롤로그 지역 지도·길목 이동·저장 위치 보완을 추가했다. 지도 데이터의 43개 노드와 48개 연결, 기존 8산 ID 대응, SVG XML 형식만 정적으로 확인했다. 사용자 요청에 따라 이번 변경 후 게임 실행·화면 검사는 하지 않았다. 아래 199개 규칙 검사와 화면 검사는 이 지도 변경 이전의 기록이다.

## 통과한 검사

- **BAT 직접 실행 전환 (2026-09-11)**: Ren’Py 소스·SDK·전용 제작 도구·이전 배포본을 제거한 뒤 `play.bat`으로 자료 가져오기와 게임 시작을 확인했다. 다른 작업 폴더에서 호출한 화면 없는 시작 검사와 NVIDIA OpenGL 렌더러로 120프레임 실행이 모두 종료 코드 0이었다. 소스만 사용하는 규칙 검사도 다시 199개, 실패 0개였다. 플레이 저장 경로는 `.local/play-saves`로 검사 저장과 분리했다. 이번 변경에서 ZIP을 생성하지 않았다.
- **규칙 검사 199개, 실패 0개.** 원자적 명령 처리, 사건 선택, 저장 복원, 길 정찰과 소비, 카드 덱의 동일 재현, 승리 후 점령 보류와 보상 1회 지급, 포로·동료 합류를 확인했다.
- **일반 캠페인 실제 행동 경로**: 솔바람채 → 달개울 → 안개재 → 청학산 → 적송산 → 철마산 → 백운령 → 태백총채 → 통일 결말. 중간에 날짜 진행·보급·모병을 사용했다. 이 경로의 자원이나 승패를 강제로 바꾸지 않았다.
- **별도 준비 상태 검사**: 패왕·초반 철마·연맹·귀환·몰락 결말의 조건, 철마 선공 후 달개울 사건 변화, 1·2·3인 덱 구성, 전투 패배와 후퇴, 51개 사건 선택의 적용을 확인했다. 이 항목은 전체 자연 플레이로 각 결말까지 간 검사가 아니라 조건을 갖춘 준비 상태를 사용한 검사다.
- **Godot 화면 입력 검사**: 타이틀 스킵 클릭 소비, 정상 도입, 첫 클릭 문장 완성·둘째 클릭 진행, SKIP의 선택지 정지, 지도·인물·편성·정찰·산길·전투 카드·턴 종료·보상·복귀·저장 복원·후퇴·결말을 검사했다. 실행마다 손패가 달라 클릭 확인 수는 67~69개이며 확인 실패는 0개였다. 마지막 배포본 검사는 67개였다.
- **실제 화면 확인**: 1280×720, 1600×900에서 렌더링한 화면을 확인했다. 그림과 글자의 최소 크기 때문에 패널을 넘는 문제를 수정했고, 카드 영역과 오른쪽 메뉴를 분리했다.
- **이전 Windows 배포 실행 기록**: `Nocrim.exe`와 `Nocrim.pck`가 있는 폴더를 실행 경로로 사용했다. 소스 프로젝트 경로를 주지 않은 상태에서 화면 입력 검사를 통과했다. 현재 기본 실행 방식은 포함된 Godot 엔진으로 소스를 여는 `play.bat`이다.

화면 입력 검사는 Godot의 Viewport에 마우스 이벤트를 넣어 **실제 버튼의 입력 전달 경로**를 통과한다. 버튼의 `pressed` 신호를 직접 호출하지 않는다. Windows 원격 마우스 조작도 시도했지만, 컴퓨터 조작 도구의 앱 접근 승인이 시간 초과되어 해당 방식의 수동 클릭 검증은 완료하지 못했다.

## 미완료 / 확인 범위 밖

- **기존 전투 그림의 배경**: 실제 PNG 검사 결과 6장 모두 RGB였다. 체크무늬가 그림에 남아 있으며, 2·3인 화면에서 다른 동료를 가리는 문제가 남아 있다. 2026-09-12부터 새 제작 기준은 불투명 단색 마젠타 또는 흰 배경이며 사용자가 직접 배경을 제거한다. 2026-09-12 담연화 후면 대기는 Sunburst의 1360×2048 RGB 마젠타 이미지로 교체하고 BAT 가져오기·시작 검사를 통과했다. 배경색은 미세하게 달라 정확히 균일한 색은 아니다. 다른 5장의 재제작은 남아 있다.
- 추가 장수 4명의 전투 그림은 이름이 적힌 임시 실루엣이다. 적장은 공통 그림이다. 별도 공격·피격 포즈가 없을 때 이동·색·참격으로 대체한다.
- 사용자 BGM·SFX가 제공되지 않아 무음 상태다. 실제 음원의 청취, 음량 균형과 루프를 검증하지 않았다.
- 모든 관계·점령 순서 조합을 자연 플레이로 끝까지 확인하지 않았다. 긴 회차의 난이도 균형, 다른 GPU·운영체제·초광폭 화면, 친구의 별도 PC는 검증 범위 밖이다.
- 제한된 검사 환경에서는 시스템 인증서 저장소를 읽지 못했다는 엔진 경고가 출력된다. 이 게임은 네트워크 기능을 사용하지 않으며 해당 경고로 플레이가 중단되지는 않았다. 실제 데스크톱 권한으로 실행했을 때에는 그 경고가 없었다.
