# 녹림전생 — 편집용 마스터 인덱스

이 패키지는 긴 통합설정집을 **편집 목적별로 분할**한 버전이다.  
캐릭터는 `설정 / 성격 / 역할 / 외형 / 색 / 무기 / 표정 / Work 프롬프트 / Negative / CG 프롬프트`를 **각 인물 한 블록 안에 모았다.**

## 어디를 고치면 되는가

**게임 대사 편집:** 실제 게임용 프롤로그 대사·화자·연출·음향은 프로젝트 루트의 `scenario/README.md`와 `scenario/chapters/00_프롤로그/common/`에서 수정한다. 이 패키지의 09번은 웹소설 원고로 유지한다. 수정 후 게임 반영을 요청하면 대본과 실행 데이터를 대조해 적용한다. 폴더의 문서를 저장하는 것만으로 게임이 자동 변경되지는 않는다.

4. 비주얼 제안 표시

## 캐릭터 시트 편집 규칙

각 캐릭터는 `<details>` 블록 하나로 묶었다.  
이름을 검색하면 그 인물의 설정부터 이미지 생성 프롬프트까지 한곳에서 확인할 수 있다.

- `비주얼 상태: 확정` → 임의로 색·머리·체형을 바꾸지 않는다.
- `비주얼 상태: 비주얼 제안` → 역할/성격은 유지하되 외형은 추후 변경 가능하다.
- 캐릭터 디자인을 수정하면 **같은 블록의 Work 프롬프트와 Negative Prompt도 같이 수정**한다.
- 별도의 비주얼 부록을 다시 만들지 않는다.
