# 녹림전생 — 게임 방식

> 편집 목적: 하루 구조, 거점 행동, 지도 이동, 전투 표현, 샌드박스 해금과 향후 구현 원칙을 한곳에서 관리한다.

# 04. 게임 루프와 시간

## 04-1. 시간

한 순은 세 행동으로 구성된다. 2026-09-13 사용자 확정: 현실의 열흘을 하루씩 세지 않고 아침·낮·밤 세 시간대로 압축한다.

- 아침
- 낮
- 밤

각 시간대에 기본 행동 1회. 세계의 사건도 날짜에 따라 독립적으로 진행된다. 플레이어가 특정 지역을 방문하지 않아도 인물이 죽거나 세력이 바뀌거나 계승전이 끝날 수 있다.

현대 시작은 `2026년 6월 상순`, 무림 시작은 `서력 732년 3월 상순`이다.

아침 → 낮 → 밤 → 다음 순 아침으로 진행한다. 상순 → 중순 → 하순 뒤 다음 달 상순이 되며, 12월 하순 다음은 다음 해 1월 상순이다. 한 달은 9행동, 한 해는 108행동이다. 프롤로그는 대본의 날짜 지정을 따르고 마지막 순의 다음 아침부터 전략 모드가 이어진다. 전략 모드 바로 시작은 서력 732년 3월 상순 아침이다.

현재 구현: 기존 turn 하나를 한 순으로 해석하고 수입·비술 회복·방문 제한·부상 회복을 순 경계에서 처리한다. 내부 이벤트 카운터와 자원 소모 횟수는 유지한다. 화면 상단은 연·월·순·현재 시간대를 표시한다. 기존 저장의 turn/ap를 초기화하지 않고 같은 순 진행도로 해석한다.

## 04-2. 산채 거점 행동

- 지도: 이동한다
- 집: 휴식한다
- 검: 훈련한다
- 책: 공부한다
- 아지랑이: 기감을 넓힌다
- 모닥불: 이야기한다

이야기 메뉴에는 연애/중요 관계 대상만 표시한다. 대상이 없으면 `아무도 없음`.

## 04-3. 공부

책 하나당 유효 독서 횟수는 대략 1~5회. 끝까지 이해한 책을 반복 클릭한다고 능력치가 무한히 오르지 않는다.

## 04-4. 지도와 이동

현재 구현 갱신(2026-09-13, 도착 대화): 이동 완료 후 하단 대화창에서 상황을 읽고 화면 클릭/Space로 선택지를 연다. ‘당신의 선택’ 제목은 생략한다. 쓰러진 사람 사건은 도와준다·상태를 살펴본다·지나간다의 세 선택지만 표시하며 일반 공격·정찰은 사건 종료 후 지도에서 주변 살피기로 다시 연다. 도움은 기존 군량 8·시간대 1 소비/민심 +6이며 살펴보기·지나가기는 무료로 사건을 끝낸다. 선택 결과를 하단 대화창에 표시하고 다음 입력으로 지도에 복귀한다. 별도 ‘지도를 펼친다’ 버튼은 없다. 공격의 전투 진입은 기존 방식 유지.

현재 구현 갱신(2026-09-13, 목각 말): 주인공의 더벅머리·평민복을 단순화한 나무색 사람 아이콘이 현재 바둑알 위에 놓인다. 도보 이동은 지도 길의 굴곡을 따라 0.65~1.5초 동안 진행하고, 완료 후 도착 선택지 또는 거점을 연다. 귀산술은 0.85초 동안 흐려졌다 나타나며 목적지로 이동한다. 이동 중 중복 입력을 막으며 이동 비용·저장 형식은 변경하지 않는다. 원본은 `godot/assets/ui/icons/protagonist_pawn.svg`.

현재 구현 갱신(2026-09-13): 바둑알 바로 옆 작은 메뉴에서 이동한다. 소유 거점은 귀산술로 돌아가며, 공격·정찰·장소별 사건은 이동 후 도착 화면의 중앙 가로 선택지로 고른다. 공격 준비 취소는 도착 선택지로 복귀한다. 도보 세 칸당 시간대 소모와 기존 전투 비용은 유지한다.

- 고지도풍 전체 지도.
- 산·도시·강·문파·시설 표시.
- 도로에는 바둑알 같은 이동 노드.
- 이동 노드 누적 3칸마다 시간대 1회 소모.
- 도로 이동 CG는 약한 상하 흔들림 2회.
- 도착 시 `[지역명]에 도착했다.`
- 사건이 없으면 `그냥 지나간다 → 나는 무사히 길을 지나갔다.`
- 등록된 산은 귀산 가능.
- 등록되지 않은 지역은 직접 가야 한다.

## 04-5. 샌드박스 해금 시점

프롤로그 이후 다음 조건을 만족하면 본격 자유 진행을 해금한다.

1. 두 번째 산의 적대 산채를 처리한다.
2. 두 번째 산에 자신의 집을 짓고 귀산 등록을 경험한다.
3. 최초 기감을 발현한다.
4. 산기·귀산·기감의 기본 원리를 강산이 스스로 정리한다.
5. `근처 산부터 정리하고, 나쁜 녹림을 몰아내고, 쓸 만한 산마다 집을 만든다`는 장기 목표를 세운다.
