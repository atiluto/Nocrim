# 녹림전생 — 어쩌다 보니 총채주

현대인이 한국식 무림의 녹림 채주가 되어 산과 사람을 모으는 **Godot 기반 PC용 비주얼 노벨 + 지역 제압 + 무공 카드 전투 게임**입니다.

현재 버전은 **Godot 0.2.0 시제품**입니다. 지도에서 산을 고르고, 동료를 편성하고, 미확인 산길과 전투를 거쳐 점령·등용·인연·결말로 이어집니다.

## 바로 실행

이 폴더의 **[play.bat](play.bat)을 더블클릭**하세요. 수정된 자료를 잠시 준비한 뒤 게임 창이 열립니다. 포함된 Godot로 현재 소스를 직접 실행하므로 압축 해제·내보내기·Python·API 키가 필요하지 않습니다. BAT와 `godot`, `.tools` 폴더를 함께 두세요.

플레이 저장은 `.local/play-saves`, 실행 기록은 `.local/play.log`에 남습니다. 개발 검사는 별도 저장 폴더를 사용합니다.

처음부터는 현대 일상 도입부터, 빠른 시작은 첫 기연부터 시작합니다. 첫 공략은 달개울채가 수월합니다. 전투 손실 뒤에는 모병과 군량을 확인하세요. 각 행동은 자동 저장됩니다.

- 8개 산채와 인접 점령·수비·탈환
- 프롤로그 산역의 옛 지도, 산·시설 이름과 바둑알 길목 이동. 제2장 출구는 준비 중
- 주인공 포함 9명, 호감도 대상 4명, 포로 등용과 석방
- 사건 25개, 선택 51개, 점령 순서와 약속에 따른 분기
- 후면 아군 1~3명, 무공 덱·손패·기력·적 행동 예고
- 점령 산 사이 귀산술과 전음
- 6개 본편 결말과 인연·우정 후일담

**남은 그림 작업:** 담연화 전투 그림은 Sunburst로 재제작한 마젠타 배경 이미지로 교체했습니다. 다른 전투 그림 5장에는 체크무늬 배경이 남아 있습니다. 앞으로는 사용자 참고 그림체와 단색 마젠타·흰 배경으로 제작하고, 배경 제거는 사용자가 직접 합니다. 나머지 그림의 재제작, 추가 장수 4명의 후면 그림, 별도 공격 포즈와 표정, 사용자 제작 음원은 아직 완료되지 않았습니다.
