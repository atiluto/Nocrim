# 녹림전생 — 어쩌다 보니 총채주

한국식 무협 세계에 떨어진 현대인이 녹림 채주가 되어 산과 사람을 모으는, **Ren’Py 기반 PC용 비주얼 노벨 + 턴제 지역제압 게임**입니다.

## 바로 플레이

Windows 배포본은 `releases/Nocrim-0.1.0-win.zip`입니다. 압축을 **전부** 푼 뒤 폴더 안의 **Nocrim.exe**를 실행하세요. Ren’Py나 Python을 별도로 설치할 필요가 없습니다. 실행 파일만 따로 옮기면 게임 자료를 찾지 못합니다.

이 작업 폴더에서는 `releases/Nocrim-0.1.0-win/Nocrim.exe`로도 바로 실행할 수 있습니다.

- 처음 화면의 **처음부터 / 무림 접속**으로 시작합니다.
- **산하도**에서 산을 선택하고 정찰하거나 출전합니다.
- **산채 경영**에서 모병·훈련·군량 구입·휴식·구휼을 합니다.
- **인물·등용**에서 교류하고 포로를 등용하거나 석방합니다.
- **하루 마감** 때 수입·군량·침공을 정산하고 자동 저장합니다.
- Esc로 저장·불러오기·설정, Enter 또는 클릭으로 대사를 진행합니다.

처음에는 달개울채를 공략하면 안정적입니다. 첫날부터 철마산을 노리려면 **철마산 정찰 → 출전 → 첫 합 기습**으로 기연에 도전하세요. 정찰한 첫 공략의 지휘부 포박 확률은 26%입니다. 실패해도 퇴각하거나 재정비할 수 있습니다.

## 이번 버전에 들어 있는 것

| 항목 | 구현 |
|---|---|
| 지도 | 본진 포함 산채 8곳, 인접 진군·점령·탈환·침공 |
| 인물 | 주인공 포함 9명, 관계 대상 4명, 포로 출신 장수 4명 |
| 이야기 | 사건 25개, 사건 내 선택지 51개, 개인 교류 장면 |
| 분기 | 첫 점령 산, 표국과 교역, 윤가 자율권, 흑기 계승, 귀환 연구, 개인 약속 |
| 전투 | 1~3명 편성, 최대 5합, 예고 대형에 대응하는 전술, 정보 기습, 부상·퇴각 |
| 비술 | 점령 산 사이 순간이동, 점령 산과 통신·원격 보급, 주둔 수비 보너스 |
| 내정 | 명령·은전·군량·병력·사기·숙련·민심·위세 관리 |
| 결말 | 국가 결말 6종과 조건을 충족한 네 인물의 인연 후일담 |
| 기록 | 수동 저장, 하루 마감 자동 저장, 대사 기록, 강호록, 결말 수첩 |

**0.1.0은 첫 플레이 가능 버전입니다.** 소규모 통일 캠페인을 끝까지 플레이할 수 있도록 제작했습니다. 장편 상업 게임 분량의 대사, 수백 개 사건, 다수의 표정·전투 애니메이션·음악·음성은 아직 들어 있지 않습니다. 구체적인 장편 확장 방향과 현재 구현 범위는 [게임 기획서](docs/GAME_DESIGN.md)에 구분해 두었습니다.

## 제작 및 수정

이 폴더 자체가 Ren’Py 프로젝트입니다. [Ren’Py 8.5.3 공식 SDK](https://www.renpy.org/release/8.5.3)로 제작·검증했습니다. 런처의 프로젝트 폴더를 이 폴더의 상위 폴더로 지정하면 Nocrim 프로젝트를 열 수 있습니다.

| 파일 | 역할 |
|---|---|
| `game/python-packages/nocrim/world.py` | 지역·인물·사건·선택지·결말 원문 |
| `game/python-packages/nocrim/engine.py` | 전투·정산·분기·등용·관계 규칙 |
| `game/script.rpy` | Ren’Py 대화와 전략 화면 진행 |
| `game/screens.rpy` | 지도·전투·인물·저장 화면 |
| `game/gui.rpy` | 해상도·색·글꼴·스타일 |
| `game/images` | 배경과 네 인물 초상 원본 |
| `docs/BRANCHES.md` | 사건 조건과 결말 조건, 스포일러 포함 |

개발용 검증은 `python tests/test_campaign.py`로 실행합니다. 공식 SDK가 `.tools` 안에 있으면 `python tools/renpy_task.py lint lint-report.txt --error-code`, `python tools/renpy_task.py test smoke --overwrite-screenshots`, `python tools/renpy_task.py test narrative --overwrite-screenshots`도 사용할 수 있습니다. Windows 배포본 재생성은 `python tools/renpy_task.py distribute`입니다.

난수 상태는 세이브에 포함되어 같은 기록을 단순히 다시 불러오면 같은 결과가 나옵니다. 화면을 열고 닫는 것만으로 확률이 바뀌지 않습니다. 테스트용 저장 기록은 실제 플레이 기록과 분리되어 있습니다.

검증 결과와 한계는 [검증 기록](docs/VALIDATION.md), 그림 원본과 생성 프롬프트는 [에셋 기록](docs/ASSETS.md)에 정리했습니다.
