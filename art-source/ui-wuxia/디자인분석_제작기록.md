# 무협 UI 개편 — 참고 분석과 제작 기록

## 판단

종이의 물리적 질감을 모든 버튼에 반복하면 원본 확대·축소에 따라 가장자리가 중복되고 시선이 분산된다. 이번에는 사진 종이를 UI 재질로 사용하지 않는다. 먹색 반투명 면, 여백, 금색 가는 선, 명확한 선택 상태를 기본으로 삼는다. 그림은 회청·먹·흙빛의 절제된 수묵으로, 캐릭터는 교체하지 않는다.

## 첨부 14장 분석 / 반영

| 번호 | 관찰 | 반영 |
|---|---|---|

기존 저장과 전투·이동·독서·호감도 규칙은 유지. 참고 게임의 로고·캐릭터·스크린샷을 게임 텍스처로 복사하지 않는다. Windows 시스템 궁서 계열 글꼴은 제목만 사용하며 없으면 번들 글꼴로 대체한다. 본문은 읽기 쉬운 기존 한글 글꼴을 유지한다.

## 생성 도구와 원화

내장 image_gen 사용. 캐릭터 생성 중단 후 결과를 게임에 반영하지 않았다. 이번 적용은 환경 원화 2장(지도 1, 배경 4분할 아틀라스 1)이다.

- `godot/assets/backgrounds/chapter_01_ink.png`: 지도.
- `godot/assets/backgrounds/wuxia_scenes.png`: 좌상 타이틀·대화, 우상 거점, 좌하 전투, 우하 산길. 원본을 편집하지 않고 Godot AtlasTexture로 영역 지정.
- `godot/assets/ui/ink_brush.svg`: 코드로 작성한 메뉴용 붓자국.

## 검증 범위

원화 내용 확인, 파일과 코드 정적 검사. 사용자 요청으로 게임/BAT/렌더 UI 검증 생략. 실제 배치와 시스템 글꼴 표시는 플레이 미검증이다. 캐릭터 파일 해시를 작업 전후 대조한다.
