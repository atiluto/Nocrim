# 히로인 원화 제작 — 2026-09-14

사용자 확정: 마영란·장소연·하령화 총 3명. 흰 배경으로만 생성하며 배경 제거는 사용자가 직접 한다. 투명화·색키·자동 배경 제거를 적용하지 않는다.

기준: universe/07의 인물 설정, 기존 11장 캐릭터 스타일 참조. 원본을 여기 보존하고 게임용 파일을 별도로 복사한다. 모든 표정은 같은 자세와 구도 유지가 목표이며 생성 결과의 미세한 차이는 검수한다.

생성 방식: 내장 image_gen. 프롬프트는 prompts/에 보관한다. 외부 API/CLI 생성이나 자동 배경 제거는 사용하지 않았다.

위 슬래시 표기는 파일 목록의 축약이다. 실제 파일명·프롬프트·생성 출력 ID·크기·SHA256·게임 복사 경로는 `manifest.json`에 하나씩 기록했다. 캐릭터는 1024×1536, 장면 그림은 1672×941. 원본과 최초 게임 복사본의 바이트 일치를 확인했다. 이후 사용자가 배경을 제거하면 게임 복사본의 해시는 달라지는 것이 정상이다.

캐릭터는 설정의 체형/머리·눈색/팔레트/역할 소품을 바탕으로 새로 생성했다. 마영란 중립 그림을 표정 차분 및 다른 두 사람의 선화·채색 기준으로 사용했다. 기존 캐릭터를 다른 사람으로 재활용하지 않았다. 배경은 실제 `godot/assets/prologue/forest_path.png`의 먹선·큰 명암 덩어리·흐린 회녹색을 참조했다. 생성 결과를 이미지로 확인하고 흰 배경과 자세/구도, 표정 및 소품을 검토했다.

## 배경 제거와 편집

모든 인물은 요청대로 흰 바탕이다. 배경을 제거한 동일 크기 PNG를 `godot/assets/prologue/`의 같은 파일명에 직접 교체한다. 자동 자르기나 인물 재배치 없이 캔버스를 유지해야 표정 전환이 안정적이다. 자세한 표정/날씨 JSON과 교체 순서는 [히로인 미술 안내](../../docs/HEROINE_ART.md), 다른 Chat용 문법은 [시나리오 편집 매뉴얼](../../scenario/시나리오_대본과_연출_편집매뉴얼.md).
