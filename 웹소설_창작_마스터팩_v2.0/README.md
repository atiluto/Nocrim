# 웹소설 창작 마스터팩 v2.0

이 묶음은 업로드된 일곱 작품의 문체·장면 운용·독백·인물 반응·히로인 진입·회차 분량과 엔딩을 분석해 만든 범용 집필 도구다.

현재 집필 중인 작품의 고유 설정은 넣지 않았다. 사용자의 수정 요청에서는 다음과 같은 일반 취향만 추출했다.

- 딱딱한 보고문보다 인물이 살아 있는 문장
- 가벼운 주인공은 심각한 상황에서도 읽기 쉬운 재치를 유지하되, 사건의 무게를 훼손하지 않음
- 행동과 결과 사이의 인과를 생략하지 않음
- 대사 뒤에 상대의 반응과 관계 변화를 충분히 보여 줌
- 짧은 문단을 쓰되 모든 문장을 기계적으로 한 줄씩 자르지 않음
- 설정·이름·성별·능력 발현 시점을 일관되게 관리함
- 최신 수정 지시를 이전 설정과 관성보다 우선함

## 가장 빠른 사용법

1. 새 대화에 `00_웹소설_창작용_마스터프롬프트.md`를 첨부한다.
2. “첨부한 마스터 프롬프트를 이번 작업의 기준으로 적용해 줘”라고 말한다.
3. `06_새채팅_입력양식.md`의 입력란을 채워 보낸다.
4. 먼저 전체 구성과 회차 분할을 받고, 확정된 회차부터 본문을 집필한다.

## 파일 구성

- `00_웹소설_창작용_마스터프롬프트.md`: 새 대화에 첨부할 자급형 지침
- `01_7작품_문체와_흐름_분석.md`: 일곱 작품에서 추출한 공통점과 차이
- `02_세계관_주인공_모드_설계.md`: 무협·현대 판타지, 가벼움·진중함 전환 규칙
- `03_주변인물과_히로인_설계.md`: 반응, 인정, 관계 진전, 첫 만남 설계
- `04_회차분량_문단_엔딩_통계.md`: 3,299회 정량 분석과 권장 수치
- `05_사용자_수정취향_일반규칙.md`: 작품 설정을 제외한 개고 원칙
- `06_새채팅_입력양식.md`: 복사해서 채우는 작업 요청서
- `07_집필_검수표.md`: 회차 납품 전 점검표와 점수표
