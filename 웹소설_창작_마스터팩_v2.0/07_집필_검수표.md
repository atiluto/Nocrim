# 웹소설 집필 검수표

## 1. 즉시 탈락 항목

아래 항목이 하나라도 있으면 납품 전에 수정한다.

- 최신 설정과 다른 이름·성별·호칭·능력 조건이 남아 있음
- 주인공이 이유 없이 새 능력을 사용해 위기를 해결함
- 히로인이 자기 목표 없이 주인공에게 즉시 호감을 보임
- 조연 전원이 같은 방식으로 감탄함
- 한 회차가 설명만 하고 선택과 결과 없이 끝남
- 심각한 피해를 농담으로 소비함
- 같은 정보를 서술, 독백, 대사로 반복함
- 참고작의 고유 문장이나 대표적인 표현을 사실상 베낌

## 2. 100점 검수표

| 영역 | 배점 | 확인 질문 |
|---|---:|---|
| 설정 보존 | 15 | 최신 설정, 이름, 시간, 능력 조건이 맞는가? |
| 인과 | 15 | 욕구→선택→행동→결과가 연결되는가? |
| 주인공 목소리 | 15 | 선택한 가벼움·진중함 모드가 말과 독백에 일관되는가? |
| 장면 변화 | 10 | 각 장면이 정보·감정·관계·목표 중 둘 이상을 바꾸는가? |
| 주변 반응 | 10 | 반응이 구체적이며 인물의 전문성과 이해관계에 맞는가? |
| 히로인·관계 | 10 | 히로인이 능동적이고 관계 진전이 사건으로 뒷받침되는가? |
| 장르 분위기 | 10 | 무협의 법도·감각 또는 현대의 절차·현실성이 살아 있는가? |
| 문단·가독성 | 5 | 공백, 문단 길이, 대사 배치가 모바일에서 읽기 좋은가? |
| 회차 성취 | 5 | 이번 화에서 독자가 확인할 수 있는 결과가 하나 이상 있는가? |
| 마지막 훅 | 5 | 짧고 구체적이며 다음 화에서 실제로 회수할 약속인가? |

- 90점 이상: 집필 완료
- 80~89점: 약한 개고 후 완료
- 70~79점: 반응·인과·회차 성취를 중심으로 재개고
- 69점 이하: 장면 설계부터 다시 검토

## 3. 문체 점검

- [ ] 첫 문단이 배경 설명보다 현재의 사람·문제·행동을 먼저 보여 준다.
- [ ] 추상명사보다 관찰 가능한 표정·몸짓·감각이 많다.
- [ ] 수식어가 같은 명사를 겹겹이 꾸미지 않는다.
- [ ] 문단마다 초점이 하나다.
- [ ] 문단 사이 빈 줄이 있다.
- [ ] 모든 문장이 한 줄로 파편화되지 않았다.
- [ ] 대사 뒤에 필요한 반응이 가까이 있다.
- [ ] 같은 어휘와 문장 끝이 연속되지 않는다.

## 4. 주인공 점검

### 가벼운 주인공

- [ ] 농담이 상황을 회피하기보다 견디는 방식으로 작동한다.
- [ ] 겉말과 속말의 온도 차가 있다.
- [ ] 농담 뒤에 실제 행동이 따른다.
- [ ] 타인의 죽음과 상실을 웃음거리로 삼지 않는다.
- [ ] 중요한 결심에서는 진심이 드러난다.

### 진중한 주인공

- [ ] 말수가 적어도 선택의 근거가 보인다.
- [ ] 감정이 행동과 망설임에 남아 있다.
- [ ] 타인의 조언을 들을 수 있다.
- [ ] 인정은 누적된 사건의 결과다.
- [ ] 인간적인 휴식이나 건조한 웃음이 있어 경직되지 않는다.

## 5. 주변 인물 점검

- [ ] 각자가 주인공의 서로 다른 면을 본다.
- [ ] 처음부터 결론을 정하지 않고 검증 과정이 있다.
- [ ] 감탄보다 호칭·거리·제안·계획이 변한다.
- [ ] 주인공이 없어도 각자의 목표가 있다.
- [ ] 적도 주인공의 힘에 맞춰 전략을 수정한다.

## 6. 히로인 점검

- [ ] 첫 등장 때 자기 목표를 위해 행동한다.
- [ ] 외모 설명이 행동보다 앞서 길게 이어지지 않는다.
- [ ] 능력과 취약점이 둘 다 사건에 작용한다.
- [ ] 말투가 다른 인물과 구별된다.
- [ ] 호감 전에 경계·호기심·검증이 있다.
- [ ] 주인공에게만 생기는 예외가 행동으로 드러난다.
- [ ] 관계 장면이 본줄기도 움직인다.

## 7. 회차 구조 점검

- [ ] 초반 10~20% 안에 앞 회차의 훅을 다룬다.
- [ ] 이번 회차의 목표가 전반부에 보인다.
- [ ] 중반에 장애·정보·관계 중 하나가 뒤집힌다.
- [ ] 선택의 결과와 비용을 보여 준다.
- [ ] 정보 획득, 관계 진전, 성공, 실패, 결심 중 하나가 완료된다.
- [ ] 마지막 1~3문단에 새 설명을 몰아넣지 않는다.
- [ ] 끝 문장이 다음 화의 구체적인 질문을 만든다.
