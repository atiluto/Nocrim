# 세계관·주인공 모드 설계

## 1. 모드 선택표

| 항목 | 무협 | 현대 판타지 |
|---|---|---|
| 현실감의 근거 | 문파·가문·관부·은원·체면 | 기관·회사·계약·법·언론·돈 |
| 강함의 증명 | 거리, 호흡, 경지 판단, 예우 변화 | 실무 결과, 기록, 시장 반응, 조직의 결정 |
| 주요 감각 | 바람, 땅, 피 냄새, 기세, 옷자락 | 소음, 화면, 교통, 사무 공간, 장비 |
| 정보 전달 | 사제 문답, 비무, 협상, 소문 | 회의, 거래, 조사, 방송, 보고 |
| 어휘 온도 | 단정한 우리말과 절제된 한자어 | 구어와 실무어, 필요한 전문용어 |
| 대표 위험 | 명예 훼손, 문파 분쟁, 생사결 | 신분 노출, 계약·법적 위험, 여론·조직 갈등 |

## 2. 무협 모드 세부 규칙

### 장면에 먼저 넣을 것

- 인물 사이의 거리와 자리
- 누가 누구에게 어떤 호칭을 쓰는지
- 손, 발, 호흡, 시선 중 하나의 변화
- 행동했을 때 발생할 문파·가문 차원의 후폭풍

### 설명 순서

1. 이상한 현상이나 행동
2. 그것을 본 인물의 판단
3. 필요한 만큼의 무공·세력 설명
4. 선택과 결과

설정집 순서로 `문파 역사 → 경지표 → 기술 설명 → 현재 장면`을 늘어놓지 않는다.

### 문체 온도

- 기본 서술은 차분하고 선명하게 쓴다.
- 전투 직전에는 문장을 짧게 하며 감각을 좁힌다.
- 관계 장면에서는 호칭, 말끝, 침묵의 길이로 감정을 드러낸다.
- 한자어를 연속으로 겹치지 않는다. 생소한 용어 뒤에는 작동 결과가 바로 보여야 한다.

## 3. 현대 판타지 모드 세부 규칙

### 장면에 먼저 넣을 것

- 시간, 장소, 비용 또는 절차 중 하나
- 주인공의 능력을 알기 전 상대가 가진 현실적인 판단
- 능력 사용 뒤 실제로 바뀐 수치, 결정, 평판, 행동

### 설명 순서

1. 익숙한 현대 상황
2. 평범한 방식으로 해결되지 않는 문제
3. 능력 또는 비범한 판단의 개입
4. 조직과 사람의 현실적인 반응
5. 이득과 함께 생긴 새 위험

### 문체 온도

- 무협보다 말이 짧고 직접적이어도 된다.
- 직업·기관별 말투를 구분한다.
- 인터넷 반응은 여론의 방향을 보여 줄 만큼만 쓴다.
- 전문용어 뒤에는 독자가 체감할 결과를 붙인다.

## 4. 가벼운 주인공 모드

### 목소리 공식

`정확한 관찰 + 개인적인 비틀기 + 해야 할 행동`

예를 들어 주인공은 상대가 강하다는 사실을 인정하면서도, 지금 자신이 처한 사소하고 현실적인 곤란을 함께 생각할 수 있다. 중요한 것은 독백이 행동을 지연시키지 않는다는 점이다.

### 적정한 재치

- 장면마다 웃길 필요는 없다.
- 긴장이 높을 때는 한두 번의 짧은 독백으로 충분하다.
- 가장 위험한 순간보다 위험 전후의 대비에서 웃음을 만든다.
- 재치는 인물의 경험과 어휘에서 나와야 한다.
- 같은 유행어, 괄호 해설, 과장된 비명을 반복하지 않는다.

### 실패하기 쉬운 형태

- 모든 인물을 속으로 조롱함
- 피해자의 고통을 펀치라인으로 씀
- 사건보다 농담이 더 오래 남음
- 주인공이 결과를 책임지지 않음
- 대사와 독백이 모두 같은 농담투라 공적 역할이 사라짐

## 5. 진중한 주인공 모드

### 목소리 공식

`관찰한 근거 + 절제된 판단 + 책임지는 행동`

말수가 적더라도 독자가 선택의 이유를 이해할 수 있어야 한다. 필요할 때는 기억, 감각, 상대의 말에 대한 해석을 짧게 넣는다.

### 주변의 인정이 생기는 순서

1. 기술이나 판단을 목격한다.
2. 우연인지 검증한다.
3. 위험 속에서도 같은 원칙을 지키는지 본다.
4. 호칭, 신뢰, 부탁, 협력 방식이 달라진다.

### 실패하기 쉬운 형태

- 감정이 없는 사람처럼 씀
- 단답만 반복함
- 늘 옳고 누구의 조언도 듣지 않음
- 조연이 감탄만 하고 자기 목표를 잃음
- 어려운 어휘를 진중함으로 착각함

## 6. 혼합 모드의 전환 신호

평상시 가볍고 위기에서 진중한 주인공이라면 독자가 전환을 감지할 신호가 필요하다.

- 독백의 농담이 멈춘다.
- 문장이 짧아지고 감각이 선명해진다.
- 별명 대신 본명이나 공식 호칭을 쓴다.
- 시선이 자기 곤란에서 타인의 위험으로 옮겨간다.
- 선택의 대가를 직접 언급한다.

위기 해소 뒤 곧바로 농담을 터뜨리기보다 결과를 확인하고 피해를 수습한 다음 평상시 온도로 돌아온다.
