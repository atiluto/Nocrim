# 새 대화용 입력 양식

## 사용 방법

새 대화에 `00_웹소설_창작용_마스터프롬프트.md`를 첨부한 뒤 아래 양식을 복사해 채운다. 모르는 항목은 비워도 된다. 결과를 크게 바꾸는 빈칸만 질문하고 나머지는 합리적으로 보완하도록 마스터 프롬프트에 설정되어 있다.

## 전체 설계부터 시작할 때

```text
첨부한 웹소설 창작용 마스터 프롬프트를 이번 작업의 기준으로 적용해 줘.

[작업 모드]
전체 설계 + 장 구성 + 회차 분할

[세계관 모드]
무협 / 현대 판타지 / 혼합 중 선택

[주인공 모드]
가벼움 / 진중함 / 평상시 가볍고 위기에서 진중함 중 선택

[시점]
1인칭 / 제한적 3인칭 / 장면별 혼합 중 선택

[로맨스 비중]
없음 / 약 / 중 / 강

[목표 독자와 핵심 재미]

[한 줄 소재]

[주인공]
- 현재 처지:
- 능력:
- 외적 목표:
- 내적 결핍:
- 절대 하지 않을 행동:

[세계의 핵심 규칙]

[주요 인물]

[히로인]
- 자기 목표:
- 능력:
- 공적 말투:
- 사적 말투:
- 주인공과 충돌하는 지점:

[고정 사실]

[원시나리오]

[원하는 작업 범위]
예: 1부 50화 / 1장 12화 / 초반 20화

[목표 분량]
예: 회당 6,000~6,500자

[특별히 피할 것]
```

## 회차 본문을 쓸 때

```text
첨부한 마스터 프롬프트와 아래 확정 설정을 기준으로 제__화를 완성해 줘.

[세계관 모드]

[주인공 모드]

[시점]

[이번 회차 제목 또는 번호]

[앞 회차 마지막 상황]

[이번 회차에서 반드시 일어날 일]
1.
2.
3.

[이번 회차에서 변해야 하는 관계]

[반드시 보존할 대사]

[이번 회차 마지막 훅]

[목표 분량]

[금지 사항]

본문만 출력해 줘. 목표 분량보다 짧으면 설명 반복이 아니라 행동 과정, 인물 반응, 결과의 수습을 보강해 줘.
```

## 기존 원고를 개고할 때

```text
첨부한 마스터 프롬프트를 적용해 아래 원고를 개고해 줘.

[개고 강도]
약: 오탈자와 어색한 문장만
중: 문체, 문단, 반응, 인과 보강
강: 사건 순서는 유지하고 장면을 재구성

[절대 바꾸지 말 것]
- 사건:
- 설정:
- 대사:

[특히 고칠 것]
- 예: 문체가 딱딱함
- 예: 주인공 독백을 더 가볍게
- 예: 주변 인물 반응이 부족함
- 예: 히로인 호감이 너무 빠름

[원고]

[출력]
개고한 본문을 먼저 출력하고, 변경 요약은 마지막에 10줄 이내로 붙여 줘.
```

## 이어 쓰기 요청

```text
기존 설정과 말투를 유지하면서 다음 회차를 이어 써 줘.

[이번에 추가된 최신 수정]

[이번 회차의 핵심 목표]

[반드시 회수할 앞 복선]

[새로 심을 복선]

[끝내는 방식]
발견 / 결정 / 재해석 / 반응 / 위협 / 여운 / 가벼운 반전 중 선택

[목표 분량]
```

## 짧은 명령 예시

마스터 프롬프트가 이미 적용된 대화라면 다음처럼 간단히 요청해도 된다.

```text
이 원시나리오를 현대 판타지, 가벼운 1인칭 주인공으로 12화 분량에 나눠 줘. 히로인은 3화에서 사건을 일으키며 등장하고, 호감보다 경계가 먼저 생기게 해 줘. 회당 6,000자 기준으로 각 화의 성취와 마지막 훅을 적어 줘.
```

```text
이 회차를 진중한 무협 문체로 개고해 줘. 주인공은 말보다 행동으로 보여 주고, 고수 두 명이 서로 다른 근거로 주인공을 재평가하게 해 줘. 마지막은 결심형으로 30자 안팎의 짧은 문단에 힘을 모아 줘.
```
